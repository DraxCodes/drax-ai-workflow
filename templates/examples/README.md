# Worked examples

Copy the **shape**, not the conclusion. These are short, filled examples of the
artifacts the workflow produces; a real artifact carries the evidence for its own
project and links to the spec, ADRs and commits rather than repeating them.

| Example | Shows |
| --- | --- |
| `council.md` | A brief, three independent seats, a recommendation with dissent, and the questions left for the user. |
| `hillclimb-run.md` | A recorded run: rubric, target, baseline, iterations, scores, evidence and the final verdict. |
| `security-report.md` | A lens report: verdict, tests, secrets/exposure, findings, routing and confidence. |

The live templates for new documents are in `templates/docs/`. The run ledger
shape is `schema/run.schema.json`; the protocol is
`benchmarks/workflow/protocol.md`.
