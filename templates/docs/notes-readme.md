# Notes for the next agent

One note per topic, named for the topic. A note earns its place when a session
lost time to something that will cost the next one the same time: a library
behaving unlike its documentation, a version-specific detail, an environment
quirk, or the reliable way to run a common procedure.

Each note records the version it was written against, the file or command that
shows it, and what to do instead. State the cause, not only the symptom. Update
the existing note rather than appending a second one; delete what stopped being
true.

This directory is for tool and environment facts. Decisions belong in ADRs,
requirements in specs, and domain terms in the glossary. A local memory tool is
a session index, not a fourth doc kind.
