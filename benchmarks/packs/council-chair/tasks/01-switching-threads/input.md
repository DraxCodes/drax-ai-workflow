# Seat proposals

**Shape.** Option B, an in-pane list. Reuse `transport.listThreads` and the existing row renderer; selection is page-local; no second state store. Option A, a topbar picker, would move the title. Option C, a palette command, hides the list behind a command.

**Experience.** Option B. The three-second read is the list itself; focus lands on the first row; the row says which thread, not what it does.

**Risk.** Option B, but the switch must void a held run with a sentence and keep the current attachment on refusal. An explicit save is not needed for a voided run.

**Chair.** Option B. The list is the body state, not a new document kind.

**Dissent.** Risk insists the held run is voided with a sentence. Experience insists focus lands on the first row. Shape warns that a second state store is a defect.
