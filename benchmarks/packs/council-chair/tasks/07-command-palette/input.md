# Seat proposals

**Shape.** Option A, extend the existing palette with the pane's actions. It reuses the command registry and keeps one source of truth.

**Experience.** Option A. The palette should show the same labels as the visible controls, so the keyboard path teaches the pointer path.

**Risk.** Option C, keep the current menus, because a palette can expose a destructive action without its confirmation. If A is chosen, destructive commands must keep their confirmation.

**Chair.** Option A, with the destructives gated behind their existing confirmation.

**Dissent.** Risk wants the current menus only. Experience wants the palette to reuse the visible labels. Shape warns that a new command list would duplicate the actions.
