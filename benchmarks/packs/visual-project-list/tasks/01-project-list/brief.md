# Visual brief — project list

A quiet, dense project list at 375 and 900, light and dark. Each row has a
project name, a path, a status badge, and Open/More actions. Rows are separated
by 12px. The subtitle sits under the title. Actions align on one baseline. The
status badge sits in its own column, never over the path. Text meets 4.5:1
contrast.

Judge only what is visible: spacing, alignment, hierarchy, contrast, truncation,
overlap, wrapping and clipping. Report findings; do not score or speculate about
code.
