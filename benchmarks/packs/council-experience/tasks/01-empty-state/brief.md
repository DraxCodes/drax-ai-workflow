# Experience brief — no threads yet

**Question.** What should the empty state for the thread list feel like at 8/10?

**Fixed point.** The pane is attached to a folder with no threads. The header is fixed: title, status pill, branch/path, actions. The list area is empty.

## Constraints (cannot move)

- One screen, 375 and 900, light and dark.
- No modal; no spinner; no marketing copy.
- The first thread must appear without a layout jump.

## Art direction

Quiet, dense, one accent. Copy is sentence case, no exclamation.

## Non-goals

Onboarding tour, sample data, illustrations.
