# Experience brief — the first project

**Question.** What should the admin page's first-run state feel like at 8/10 when there are no projects?

**Fixed point.** The admin page is open and empty. There is no project to show.

## Constraints (cannot move)

- No tour, no sample data, no modal.
- The first project appears without a layout jump.
- One screen at 375 and 900, light and dark.

## Art direction

Quiet, dense, one accent. Copy is sentence case, no exclamation.

## Non-goals

An onboarding checklist, demo projects, a wizard.
