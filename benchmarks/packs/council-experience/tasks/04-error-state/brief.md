# Experience brief — a project page fails to load

**Question.** What should a failed project page feel like at 8/10?

**Fixed point.** The page header is fixed. The body cannot load the project: the failure may be a network error or a missing project.

## Constraints (cannot move)

- One screen, 375 and 900, light and dark.
- One sentence, no stack trace, no blame.
- The header and the back action keep their positions.

## Art direction

Quiet, dense, one accent. Copy is sentence case.

## Non-goals

An error code catalogue, a support form, automatic retry loops.
