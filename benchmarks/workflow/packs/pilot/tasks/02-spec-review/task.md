# 02 — Review the signup spec for missing obligations

Use the `completeness` rubric. The spec below is short; a short spec that decides
every obligation beats a long one that decides none.

## Objective

Review `input/spec.md` and list the obligations it leaves undecided. For each gap,
name the actor, the state or failure it affects, the cost of leaving it open, and a
concrete decision the author could make.

## Evidence that counts as done

- A filled obligation inventory: actors, inputs, states, failure, permissions, data
  lifecycle, limits, observability, compatibility, cost, security, dependencies,
  non-goals.
- Each gap is a finding with the spec section it belongs in.
- No rewriting of the spec; this is a review.

## Scope

- Read `input/spec.md` only.
- Do not invent product requirements that the spec's goal excludes.

## Non-goals

Visual design, copywriting and pricing are out of scope.
